# Keyboard

The keys the host presses, as **typed keys**, **key state**, or both. Typed keys are a port holding the oldest key event, with an interrupt raised when one arrives, for reading text. Key state is ports holding a bit for each key held, and for each key pressed since it was last read, for games.

### Wiring and settings

For typed keys, the keyboard is wired to one port, and one interrupt line on the cores it is connected to. For key state, it is wired to 10 consecutive ports, with no interrupt. A keyboard has either or both (see [Wiring and settings](3-Devices.md#wiring-and-settings)). It has no memory, and no settings.

### Typed keys

* **Reading:** When a key event is waiting, it is in port word 0, and the port's status is set. Read it with `INS` (or `IN`), which clears the status. The keyboard puts the next key there the cycle after.
* **The interrupt** is raised each time a key event is put in the port. So each key raises it once, when it becomes readable, and a handler that reads one key with `INS` is interrupted again for the next.
* **The queue** holds 16 key events not yet in the port. Keys pressed while it is full are lost, as on old keyboards.
* **Writing** to the port sets its status, which the keyboard takes as a key not yet read, so it puts no key there until the status is cleared.

#### Key events

A key event is a word: the low byte is the key, and the high byte the modifier keys held with it. The host translates each key by its own keyboard layout, so a key event is the character the key types there.

| Key                           | Code               |
| ----------------------------- | ------------------ |
| Characters                    | ASCII, 20h to 7Eh  |
| Enter, Tab, Backspace, Escape | 0Dh, 09h, 08h, 1Bh |
| `Ctrl` with `A` to `Z`        | 01h to 1Ah         |
| Delete                        | 7Fh                |
| Up, Down, Left, Right         | 80h, 81h, 82h, 83h |
| Home, End, Page Up, Page Down | 84h, 85h, 86h, 87h |
| Insert                        | 88h                |
| F1 to F12                     | 90h to 9Bh         |

| Modifier | Bit   |
| -------- | ----- |
| Shift    | 0100h |
| Ctrl     | 0200h |
| Alt      | 0400h |

### Key state

Each of the 10 ports holds 16 keys: bit `i` of port `n` (counting from the first) is the key with code `16n + i` (see [Key codes](#key-codes)).

| Word | What                                          |
| ---- | --------------------------------------------- |
| 0    | The keys held                                 |
| 1    | The keys pressed since the port was last read |

* **The status** is set while word 1 isn't 0.
* **Reading** a port clears its status (`IN` does, as well as `INS`), which takes its pressed keys: the keyboard clears them from word 1, keeping any pressed since. So read the dword, with `IN`, or with `INS`, which reads only when a key on the port was pressed, to get both words at once. Reading word 0 alone takes the pressed keys without seeing them.
* **A tap is never missed:** a key pressed and released between two reads is pressed but not held. A key held down is pressed once, however long it is held.
* **Each port has its own lock,** so a program reading the ports while the keyboard updates them may see some ports from before a change and some from after. Keys on one port change together.
* **Writing** to a port changes it until the keyboard next writes it, which it does when one of its keys changes, or its pressed keys are taken. A write that sets the status makes `INS` read it.
* **Timing:** the keyboard writes a port with no cycles of its own, so it waits only while a core holds the port. Keys change only as the host reports them, such as once a frame.

#### Key codes

A key's code is where it is on the keyboard, whatever the host's layout, named by the key event of that key without Shift on a US keyboard. So letters are their lower case codes, and the keys a US keyboard marks `W`, `A`, `S`, and `D` keep their codes on an AZERTY keyboard, which marks them `Z`, `Q`, `S`, and `D`.

| Key                                   | Code               |
| ------------------------------------- | ------------------ |
| Backspace, Tab, Enter, Escape         | 08h, 09h, 0Dh, 1Bh |
| Space                                 | 20h                |
| `'` `,` `-` `.` `/`                   | 27h, 2Ch to 2Fh    |
| `0` to `9`                            | 30h to 39h         |
| `;` `=`                               | 3Bh, 3Dh           |
| `[` `\` `]` `` ` ``                   | 5Bh to 5Dh, 60h    |
| `A` to `Z`                            | 61h to 7Ah         |
| Delete                                | 7Fh                |
| Up, Down, Left, Right                 | 80h to 83h         |
| Home, End, Page Up, Page Down, Insert | 84h to 88h         |
| Left Shift, Right Shift               | 89h, 8Ah           |
| Left Ctrl, Right Ctrl                 | 8Bh, 8Ch           |
| Left Alt, Right Alt                   | 8Dh, 8Eh           |
| F1 to F12                             | 90h to 9Bh         |

Other keys (the keypad, Caps Lock, Num Lock, Scroll Lock, Print Screen, Pause, and the Windows and menu keys) aren't in the key state, and the other codes are never set.
