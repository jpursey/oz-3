# OZ-3 Manual

All documentation on the OZ-3 virtual CPU, associated tools, devices, and the Ozzy Computer.

## Contents

* **[History](1-History.md):** A brief backstory to the creation of the OZ-3. This answers the question of "why". Why does this exist? Why is it "3"? Why is it named "OZ"?
* **[Specifications](2-Specifications.md):** The "hardware" specifications for the OZ-3.
* **Tools:** All the various tools that you can use with the OZ-3 CPU.
  * `oz3ism`: The instruction set assembler. It assembles [instruction set source](2.3-Instruction-Set-Source.md) (`.izm`) into C++ for an `InstructionSetDef`, which is how the default instruction set is built.
  * `oz3asm`: The official assembler for OZ-3. Basic, but powerful. It assembles [program source](2.5-Program-Source.md) (`.oza`) into [program files](2.4-Program-Files.md) (`.oz3`) of RAM and ROM segments that can be loaded directly into the OZ-3 memory and run, or into [bare programs](2.4-Program-Files.md#bare-programs) that load at any word, and optionally writes a map for the debugger (`.oz3map`) and a listing (`.oz3lst`) (see [Program Source](2.5-Program-Source.md#oz3asm)). A host application can also assemble program source itself (see [Program Source](2.5-Program-Source.md#assembling-a-program)).
  * `oz3dsk`: The disk image tool. It makes and formats [disk images](3.5-Disk-Drive.md#images) (`.ozd`) for the disk drive, and copies files on and off them (see [Disk Drive](3.5-Disk-Drive.md#oz3dsk)).
  * `ozzy`: Runs an Ozzy Computer in the console (see [Ozzy Computer](4-Ozzy-Computer.md#running-ozzy)).
  * `oz3dbg` (planned): The official debugger for OZ-3. It can read .oz3map files to step through code generated by `oz3asm`, set breakpoints, watches, etc.
* **[Devices](3-Devices.md):** The ready-made devices that run beside the cores, on ports, interrupts, and memory pages, which any OZ-3 processor can have, wired and set up as it likes.
  * **[Teletype](3.1-Teletype.md):** A port that writes text to the host.
  * **[Keyboard](3.2-Keyboard.md):** A port of key events, with an interrupt for each one.
  * **[Screen](3.3-Screen.md):** A page of character cells and control words, with a redefinable character set.
  * **[Timer](3.4-Timer.md):** A periodic interrupt, and a port that answers with the cycle count, the time since power on, and the host's date and time.
  * **[Disk Drive](3.5-Disk-Drive.md):** A smart drive that owns the file system on a disk image, which a program opens, reads, writes, and lists files on by name, through three ports and an interrupt.
* **[Ozzy Computer](4-Ozzy-Computer.md):** The Ozzy computer is a virtual machine you can run your OZ-3 programs in: its config file, its memory, the machine table that describes it to programs, and running it in the console with `ozzy`.
